# 🏙️ City Clean-Up — Open Source & SDG Classroom Quiz Game

An interactive educational game that combines **Open Source education, teamwork, environmental awareness, and gamification**.

City Clean-Up challenges students to answer questions about Open Source technologies, digital public goods, and sustainability while restoring a polluted virtual city. Every correct answer helps clean up the environment and brings the class closer to victory.

The project is designed for classroom activities, university lessons, team competitions, and interactive learning sessions.

# 🎮 Current Game Features

## 1. Interactive City Map

The game features an illustrated virtual city containing **10 interactive trash hotspots**.

Each hotspot represents a polluted area. Students select a hotspot to open a quiz question. Correct answers remove the trash and contribute to the city's restoration.

The objective is to clean all active areas and restore the virtual city.

## 2. Team-Based Gameplay

Players can choose between three game modes:

- **Whole Class:** The entire class plays together and shares one score.
- **2 Teams:** Students compete in two teams.
- **3 Teams:** Students compete in three teams.

In team modes, turns rotate between teams after incorrect answers.

## 3. Quiz System

The game includes 30 questions divided into three difficulty or progression waves.

| Question Set | Questions |
|---|---:|
| Wave 1 | 1–10 |
| Wave 2 | 11–20 |
| Wave 3 | 21–30 |
| Random 10 | 10 randomly selected questions |

Each question contains four possible answers, with only one correct option.

**Scoring rules:**
- Correct answer: +100 points.
- Incorrect answer: No points.
- Correct answer: The selected city area is cleaned.
- Incorrect answer: A hint is displayed, and the turn passes to the next team in team modes.

## 4. Built-in Question Editor

Teachers and game administrators can manage quiz content directly inside the application.

Available functionality:

- Add new questions.
- Edit existing questions.
- Delete questions.
- Import multiple questions using bulk-paste format.
- Restore the default demo questions.

Question changes are automatically saved in browser local storage.

## 5. Bilingual Interface

The application supports two languages:

- English
- Russian

Players can switch between languages using the language selector.

## 6. City Restoration

The city changes as players answer questions correctly.

Each cleared hotspot contributes to the overall cleanliness progress. The game tracks completed areas and displays the restoration progress.

The final objective is to clear all active hotspots and complete the city restoration challenge.

## 7. Mr. Meow Mascot

Mr. Meow is the game's animated assistant and mascot.

The character adds personality to the experience through reactions and visual feedback during gameplay.

## 8. Sound Effects and Animations

The game includes interactive visual and audio elements to make classroom activities more engaging.

These include:
- Animated interactions.
- Sound effects.
- Visual feedback for correct and incorrect answers.
- Animated city elements.
- Mascot reactions.

## 9. Responsive Design

The interface is designed to work across different screen sizes, including:

- Desktop computers.
- Classroom projectors and large displays.
- Laptops.
- Tablets.
- Mobile devices.

# ❄️ Save Mr. Meow! — Winter Mini-Game

Players must collect useful resources to help him stay warm and build a comfortable shelter before time runs out.

- Move left and right using keyboard arrow keys.

- Collect useful resources.
- Avoid obstacles.
- Track collected resources using an inventory.
- Monitor progress through a warmth meter.

### Required Resources

Players must collect the following items:

| Resource | Required Amount |

- Ice blocks 🧊

After successfully collecting all required resources, players will see Mr. Meow becoming warm and happy.

The completion scene will feature:

- A shelter.
- A warm blanket.
- A campfire.
- Fish for Mr. Meow.

Successful completion will grant:

| Reward | Description |
|---|---|
| +100 Meow Coins | In-game currency |

# 🕹️ How to Run

City Clean-Up is currently a standalone HTML application. It does not require a backend server, package installation, or a build process.

### Requirements

- A modern web browser.
- An Internet connection for external resources loaded through CDNs.

### Launch Instructions

1. Download or clone the repository.
2. Locate `city_clean_up_classroom_quiz_game.html`.
3. Open the HTML file in a modern web browser.
4. Click **Start Game**.
5. Select a question set and team mode.
6. Start cleaning the city!

**Note:** The application currently loads Tailwind CSS and Google Fonts from external CDNs. An Internet connection is required for these resources to load correctly.

# 📖 How to Play

## Step 1 — Choose a Question Set

Select one of the available question sets:

- Wave 1: Questions 1–10.
- Wave 2: Questions 11–20.
- Wave 3: Questions 21–30.
- Random 10: A randomly selected set of 10 questions.

## Step 2 — Select a Team Mode

Choose how the class will participate:

- Whole Class.
- 2 Teams.
- 3 Teams.

## Step 3 — Select a City Hotspot

Click one of the glowing hotspots on the city map to open a quiz question.

## Step 4 — Answer the Question

Read the question and select one of the four available answers.

## Step 5 — Earn Points and Clean the City

A correct answer awards 100 points and removes the trash from the selected area.

An incorrect answer displays a hint. In team modes, the turn passes to the next team.

## Step 6 — Complete the Challenge

Continue answering questions until all active hotspots have been cleared.

The game displays a victory screen when the city restoration challenge is completed.

# 📝 Customizing Quiz Questions

Teachers can manage quiz questions using the built-in **Questions** editor.

### Available Operations

- Create new questions.
- Modify existing questions.
- Delete questions.
- Import multiple questions.
- Restore the default demo questions.

### Bulk Import Format

Questions can be imported using the following structure:

```text
Q: What does DPG stand for?

A: Digital Programming Group

B: Digital Public Goods

C: Data Protection Guide

D: Digital Product Generation

ANSWER: B

HINT: Open digital resources for public good.

FACT: Certified DPGs help achieve the UN SDGs.
```

### Import Rules

- Every question must start with `Q:`.
- Four answer options must be provided (`A`, `B`, `C`, `D`).
- The correct answer must be specified using `ANSWER:`.
- Optional hints can be added using `HINT:`.
- Additional explanations or facts can be added using `FACT:`.

### Data Storage

Question modifications are automatically saved in the browser's local storage.

This means:

- Changes remain available in the browser where they were made.
- Changes are not automatically synchronized between devices.
- Other players will not automatically receive the modified question set.

# 🎯 Project Goals and Educational Value

City Clean-Up aims to make technical education more interactive and accessible.

The project combines three main learning areas:

**1. Open Source Education**

Students explore concepts related to open-source software, GitHub, software licenses, digital public goods, and collaborative development.

**2. Environmental Awareness**

The city-restoration mechanic encourages students to think about waste management, recycling, renewable energy, and sustainable communities.

**3. Teamwork and Gamification**

Points, team competition, interactive questions, and future customization rewards encourage participation and collaborative learning.

The project is also inspired by the United Nations Sustainable Development Goals (SDGs), particularly:

- **SDG 4 — Quality Education**
- **SDG 11 — Sustainable Cities and Communities**
- **SDG 12 — Responsible Consumption and Production**
- **SDG 13 — Climate Action**
